基于 Ollama + LangChain 的本地RAG文档问答系统

> 个人AI应用产品实战项目｜全本地运行，私有PDF文档问答助手



📌 项目简介

面向有隐私保护、离线使用需求的用户，打造私有化文档问答工具。

支持上传PDF文档，基于文档内容进行自然语言问答；所有数据、检索、大模型推理全部在本地执行，不调用云端大模型API，敏感数据不会外传。

前端使用Streamlit快速搭建Web交互页面，开箱即用。



✨ 核心功能（当前MVP版本）

\- ✅ 上传PDF文件（单文件上限200MB）

\- ✅ 文档自动解析、文本切分、向量化存入本地向量库

\- ✅ 输入问题，基于文档内容检索并生成回答

\- ✅ 断网可使用，无需连接大模型服务商



📋 后续迭代规划

\- 增加对话历史管理

\- 文档列表管理：查看、删除、重新解析文档

\- AI回答附带原文引用片段，降低幻觉

\- 加载中状态提示、解析失败、无检索结果等异常兜底提示

\- 支持更多文件格式（Word、TXT）



🛠️ 技术栈

\- 大模型\&向量：Ollama（本地部署LLM与Embedding模型）

\- 编排框架：LangChain

\- Web界面：Streamlit

\- 向量库：Chroma

\- 开发语言：Python

⚠️ 运行前置条件

1\. 本机提前安装并启动 Ollama

2\. 拉取对应的大模型、嵌入模型

3\. 安装项目依赖：`pip install -r requirements.txt`

4\. 启动命令：`streamlit run app.py`



💡 项目亮点

解决了云端问答工具两大痛点：

1\. 敏感文档上传云端存在数据泄露风险

2\. 依赖网络与API调用，产生持续费用、离线场景无法使用
