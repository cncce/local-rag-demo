测试基本信息



项目：基于 Ollama+LangChain 本地 RAG 文档问答系统

测试版本：V1.0 MVP

测试环境：本地，Ollama 已启动、模型已拉取

测试目的：验证产品功能、边界场景、异常场景是否符合 PRD 需求



表格



| 用例 ID | 测试模块 | 测试场景 | 操作步骤 | 预期结果 | 测试结果 |

| --- | --- | --- | --- | --- | --- |

| TC001 | 文档上传 | 上传正常 PDF 文件 | 1. 打开页面2. 选择合法无加密 PDF 上传 | 上传成功，文档自动解析、向量化，页面提示解析完成 |  |

| TC002 | 文档上传 | 上传非 PDF 文件（txt/png） | 1. 选择图片 /txt 文件上传 | 识别格式错误，弹出友好提示，不进入解析流程 |  |

| TC003 | 文档上传 | 上传加密 / 损坏 PDF | 1. 选择加密或者损坏 PDF 上传 | 提示文档解析失败，告知更换文件 |  |

| TC004 | 问答功能 | 提问文档内存在的内容 | 1. 解析完成 PDF2. 提出文档内包含的问题 | 大模型返回贴合文档内容的答案，不编造无关信息 |  |

| TC005 | 问答功能 | 提问文档不存在的内容 | 1. 解析完成 PDF2. 提问文档里没有的信息 | 回复说明在当前文档未查到相关内容，不编造幻觉答案 |  |

| TC006 | 问答功能 | 输入空问题 | 1. 输入框不填内容，点击提问 | 提示请输入问题，不触发检索和生成 |  |

| TC007 | 离线验证 | 断开外网，本地 Ollama 保持运行 | 1. 电脑断网2. 上传 PDF、发起提问 | 功能正常运行，可正常解析文档、回答问题 |  |

| TC008 | 边界 | 上传接近上限的 PDF（200MB） | 1. 选择接近 200MB 的 PDF 上传 | 可以正常解析（耗时变长） |  |



测试总结



1\. 核心主流程（上传 PDF→解析→问答）可以正常跑通；

2\. 异常场景都有兜底提示，不会直接崩溃；

3\. 满足 MVP 阶段验收标准；

4\. 待优化点：当前版本缺少答案引用溯源、多文档管理，留到二期迭代。
